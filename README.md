## 📌 Project Mission

**ARMONIA** is a decentralized, zero-cost, open-source community framework designed to be downloaded and deployed by any church, parish, NGO, or civic group worldwide. 

Its primary purpose is to prevent extreme isolation, somatic trauma degradation, and silent crises by providing three core pillars:
1. **Unconditional Daily Food** (a loaf of bread / a warm meal) with no paperwork or questions asked.
2. **A Neutral Sanctuary Space** for rest and empathetic listening (de-medicalized, non-bureaucratic).
3. **A 24/7 Helpline & Dispatch System** operated by trained local volunteers.

🚀 Quick Start Guide (5-Step Deployment)
1. Clone or Download the Repository
Parish members or community volunteers can download the repository as a ZIP file or via command line:

Bash
git clone [https://github.com/your-community/armonia-framework.git](https://github.com/your-community/armonia-framework.git)
cd armonia-framework

```


2. Allocate a Sanctuary Space
Identify an annex, a parish room, or a ground-floor church hall. Use /02_SPATIAL_&_LOGISTICS/sanctuary_room_layout.pdf to design a warm, comfortable space (tea/coffee station, acoustic privacy, zero medical/administrative look).

```


3. Set Up Daily Bread & Meals
Open /03_FINANCIAL_MODELS/dynamic_budget_calculator.xlsx and adjust the number of meals/bread loaves provided daily based on local church resources.

```


4. Launch the Local Helpline
Run the lightweight dispatch tool in /04_DISPATCH_SOFTWARE/ on any parish laptop or low-cost mobile phone. Follow local_dispatch_setup.md to route calls to on-duty volunteers.
```


5. Print and Distribute Assets
Navigate to /05_MULTILINGUAL_ASSETS/, insert your local church/parish phone number onto the vector posters, and distribute them across university dorms, bus stops, parks, and high-risk urban areas.

```


🛠️ The "Everything FREE" Rule
When interacting with individuals in severe distress or somatic trauma:

No ID or Proof Required: Eliminates administrative panic and triggers.

No Religious or Ethnic Conditions: Open unconditionally to anyone in need.

Transparent Messaging: Always use positive, clear phrasing:

"A warm meal. An open hand. Everything FREE."

```
